# v1.3 — Analysis and a richer simulation workspace

Target: local, tested upgrades by 21:00 America/Toronto on 16 November 2026. Start from the published v1.2 release and current `main`; keep the local preview available and merge tested increments into `master` before publication.

1. Implemented: independently cached/refreshable measured sectors, speed traps and pit visits, preserving coordinates, clocks and bookmarks.
2. Implemented: race analysis desk, exports and approximate sector map references with explicit quality/scope handling.
3. Implemented: past-only pace-baseline training against held-out pit-free laps. This is a pace diagnostic rather than proof of counterfactual pit strategies.
4. Implemented: connected pit-lane editing, driver grid/pace/service settings, deterministic stops/rejoins, simulated order and saved setups.
5. Implemented: deferred tool bundles and recovery, indexed replay lookups, setup/preview helpers, expanded API/concurrency/browser checks and release/demo documentation.

Provider reference: https://openf1.org/docs/ . Sector durations are measured lap attributes; a missing value stays missing. Pit-lane traversal time is distinct from stationary service time and from net race-time loss. Historical location coordinates remain approximate.

No accounts, paid services, public deployment, multiplayer, 3D car models or commercial data licensing are needed for this local increment.

See [the release guide](V1.3.md) and [demo](DEMO.md) for the finished behavior and validation.
